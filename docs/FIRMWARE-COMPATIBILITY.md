# Совместимость и восстановление сети

XRoute выпускается в формате APK для OpenWrt 25.12: x86_64,
aarch64_generic и aarch64_cortex-a53. Для перехвата нужны firewall4 и
модули nftables socket/TProxy; установщик получает зависимости из репозитория
прошивки.

Команда `resproxyd doctor` проверяет доступные возможности firewall и показывает
последний сохранённый инцидент. Она не меняет настройки сети.

При аварийном выходе или неудачном запуске XRoute пытается восстановить последнюю
рабочую конфигурацию. Если ядро остаётся недоступно, снимается перехват в неработающий
прокси и возвращается прежний DNS. Обычный WAN и локальный доступ к роутеру сохраняются,
явно выбранные строгие блокировки продолжают действовать. Явное выключение XRoute
возвращает обычный WAN без защиты маршрутных листов.
Отказ отдельного прокси при работающей службе обрабатывается по действию,
выбранному в правиле.

Для TProxy XRoute временно настраивает включённый bridge netfilter и возвращает
исходные значения при остановке. Системные `src_valid_mark` и `rp_filter`
остаются включёнными, если их использует VPN.
